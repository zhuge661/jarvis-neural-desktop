中文全息 AI 桌面首次开源技术预览，源码采用 MIT 许可并保留上游署名。

## 下载

- **Apple / M 系列芯片**：`Jarvis-macOS-arm64-v1.0.0.zip`
- **Intel 芯片**：`Jarvis-macOS-x64-v1.0.0.zip`
- 需要 macOS 13 或更新版本。

完整解压后双击包内 `首次安装.command`。脚本将应用安装到个人“应用程序”目录并校验本地签名；以后直接打开“贾维斯.app”。已有同名应用时脚本会停止，不会自动删除旧应用或用户数据。

## 包含功能

全息神经网络、双手缩放与 OK 锁定、文档/照片光点与右拖阅读、可移动缩放的卡片、逐字回复、多模型 API、火山实时语音，以及可选本机中文识别与云健朗读。

## 纯净与验证

- 包内没有作者的 API、个人配置、文档、照片、聊天记录或知识库连接；API 由使用者自行配置。
- Apple 芯片及 Intel 包均在对应的 GitHub 托管 Mac 环境构建，完成 ad-hoc 签名校验和原生桌面启动 / WebGL 渲染检查。
- Intel 托管测试机没有可用 GPU，因此该架构的 CI 启动检查使用 SwiftShader 软件渲染；正常打开应用使用默认图形设置。实际设备的显卡性能仍需实机体验。
- 初始资料、模型配置、语音配置均为空；本机模拟接口、资料导入/重启保留、手势状态机测试通过。
- 发布前验证包内程序源码与公开仓库一致，并检查 ZIP 完整性、用户数据目录排除及权限/符号链接。结果见 `release-audit.json`，校验值见 `.sha256` 文件。
- 未取得 Apple Developer ID 签名或苹果公证。首次打开可能需要按 macOS“隐私与安全性”提示确认来源，不要关闭系统安全防护。
- 摄像头手感、麦克风和真实云端语音通话尚需使用者在自己的设备与账户下验证。

完整功能、配置、隐私与上游许可说明请阅读 [README](https://github.com/zhuge661/jarvis-neural-desktop#readme)。
